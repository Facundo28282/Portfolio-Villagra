# Portfolio de Fútbol de Barrio ⚽

Sitio web informal dedicado al fútbol entre amigos, picos de fin de semana y torneos de barrio.

## 🚀 Archivos del Proyecto
- `index.html`: Maquetación con todas las secciones de fútbol amateur.
- `css/estilos.css`: Estilos verdes futboleros y diseño adaptable a celulares.
- `js/script.js`: Menú desplegable responsivo y desplazamiento suave.
- `bitacora_ia.md`: Bitácora del proceso y ajustes realizados.
